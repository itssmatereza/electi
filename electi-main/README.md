# ELECTI

Sitio público y portal de alumnos de ELECTI — Escuela de Liderazgo y Gestión
de Proyectos, programa de Fundación Unión Estudiantil.

- **Sitio público** — 13 páginas generadas desde `src/` con `python3 build.py`.
  Ver [LEEME.md](LEEME.md) para saber qué se edita y cómo.
- **Portal de alumnos** — `portal/index.html`, independiente del resto.

Publicado en Cloudflare Pages.
